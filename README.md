# Mini Business ERP System

A web-based ERP application built using Flask and SQLite.

---

# Features
- Inventory Management
- Sales Management
- Reports Dashboard
- Low Stock Alerts
- Sales Analytics

---

# Technologies Used
- Python
- Flask
- SQLite
- Bootstrap 5
- HTML/CSS

---

# ERP Concepts Used

This project simulates basic SAP ERP concepts:
- SAP MM (Materials Management)
- SAP SD (Sales & Distribution)

---

# Your Project vs Real SAP ERP

| Mini ERP Project Module | Real SAP Equivalent |
|---|---|
| Inventory Module | SAP MM (Materials Management) |
| Sales Module | SAP SD (Sales & Distribution) |
| Reports Module | SAP BI / Analytics |
| Dashboard | SAP Fiori Dashboard |

---

# Modules

## Inventory Module
Manage products and stock.

## Sales Module
Create sales and reduce stock automatically.

## Reports Module
View total sales and low stock alerts.

---

# Installation

```bash
pip install flask
python app.py
```
